      How to play

      Name the programming language behind today's five lines of code. You get 6 guesses.

      At first only the shape of the code shows: punctuation, operators and indentation stay put, while every word and number is blanked out.

      xxxxx xxxxx = xxx(xx); → const total = sum(xs);

      Every wrong guess unmasks one more line and scores your guess against the answer:

      • Static matches the answer
      • OOP partly matches (paradigms overlap, or the year is within 5)
      • VM doesn't match
      • 1995 ↑ the answer is newer (↑) or older (↓)

      Year is first public release. Runs is how it's usually executed. Blocks is how the syntax marks a block: braces, indentation, keywords like end, or parentheses.
